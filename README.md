# Алиса → OpenAI: простой голосовой помощник

Говорите: «Алиса, запусти навык [ваше активационное имя]», затем задавайте вопросы.
Колонка распознаёт речь, этот сервер отправляет текст в OpenAI Responses API,
Алиса озвучивает ответ. Это отдельный API-помощник: история и память вашего
чата ChatGPT сюда не переносятся.

## Что уже сделано

- `POST /alice`: протокол Яндекс Диалогов 1.0, приветствие, вопросы, выход.
- Короткие ответы до 1024 символов, последние четыре пары реплик в сессии.
- Если ответ не готов за 2,5 секунды, запрос продолжает выполняться в фоне.
  Скажите «готово» через несколько секунд. Пока он выполняется, новые вопросы
  не отправляются: дождитесь ответа и затем задайте следующий вопрос.
- Ошибки API озвучиваются без раскрытия ключей; повторы последнего сообщения
  не создают новый запрос. `сброс` очищает историю, `выход` завершает разговор.
- `.env.example`, `.gitignore`, Render Blueprint и проверки GitHub Actions.

## 1. Подготовьте OpenAI

Создайте API-ключ в [OpenAI Platform](https://platform.openai.com/api-keys)
и настройте оплату/баланс API в своём аккаунте. Ключ вводится только в локальный
`.env` или настройки хостинга. Не отправляйте его в чат и не загружайте в GitHub.
Выбрана `gpt-4.1-mini`; если она недоступна вашему проекту, укажите доступную
текстовую модель Responses API в `OPENAI_MODEL`.

## 2. Локальный запуск (Python 3.12, PowerShell)

Откройте терминал в этой папке:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000 --no-access-log
```

Заполните `OPENAI_API_KEY`. `ALICE_SKILL_ID` можно добавить после создания навыка.
Откройте `http://127.0.0.1:8000/health`: ожидается `configured: true`.
Сам сервер HTTP; для Алисы нужен публичный HTTPS, который предоставит хостинг.

Проверка без ключа: приветствие работает, а вопрос возвращает просьбу настроить ключ.
В другом окне PowerShell:

```powershell
$body = @{
  version = '1.0'
  session = @{ session_id = 'local-test'; skill_id = 'test'; message_id = 0; new = $true }
  request = @{ type = 'SimpleUtterance'; command = '' }
} | ConvertTo-Json -Depth 5
Invoke-RestMethod -Uri http://127.0.0.1:8000/alice -Method Post -ContentType 'application/json; charset=utf-8' -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
```

Для вопроса измените `command`, увеличьте `message_id` и задайте `new = $false`.
При заполненном `ALICE_SKILL_ID` используйте этот же ID в тесте.

## 3. GitHub

Создайте пустой приватный репозиторий `alice-openai`. Загрузите содержимое этой
папки в его корень: `app.py`, зависимости, README, `render.yaml`, `tests/`,
`.github/`, `.gitignore`, `.python-version`, `.env.example`.
Через веб-интерфейс проверьте, что скрытые файлы также загрузились.
`.env` и `.venv` не загружайте. Проект подготовлен для GitHub, но автоматически
не опубликован и не закоммичен.

## 4. Публичный HTTPS на Render

1. Войдите в [Render](https://dashboard.render.com/) и подключите репозиторий.
2. Создайте **Web Service**, выберите Python.
3. Build Command: `pip install -r requirements.txt`.
4. Start Command: `uvicorn app:app --host 0.0.0.0 --port $PORT --workers 1 --no-access-log`.
5. Выберите постоянно работающий тариф. Это платная операция; проверьте
   актуальную стоимость перед созданием. Бесплатный сервис засыпает после
   простоя, а пробуждение может нарушить лимит времени Алисы.
6. В Environment добавьте `OPENAI_API_KEY`, `OPENAI_MODEL=gpt-4.1-mini`
   и позже `ALICE_SKILL_ID`. Ключ задайте как секрет, не в файле репозитория.
7. Health Check Path: `/health`. После успешного запуска откройте
   `https://ВАШ-СЕРВИС.onrender.com/health`.
8. Адрес для Яндекса: `https://ВАШ-СЕРВИС.onrender.com/alice`.

Альтернатива: создать Blueprint из `render.yaml`; в нём уже указан платный
`starter`. Перед подтверждением проверьте стоимость. HTTPS обслуживает Render,
домен и сертификат отдельно покупать не требуется.

## 5. Навык Яндекс Диалогов

1. Откройте [консоль Яндекс Диалогов](https://dialogs.yandex.ru/developer/).
2. Создайте навык Алисы, укажите название и активационное имя,
   например «Домашний советчик» (если такое имя доступно).
3. Выберите backend через webhook и вставьте HTTPS-адрес `/alice`.
4. В общих сведениях скопируйте ID навыка и добавьте его в `ALICE_SKILL_ID`
   на Render, затем примените настройки/перезапустите сервис.
5. Сохраните изменения и на вкладке тестирования задайте вопрос.
   Проверьте приветствие, ответ, «готово», уточнение и «выход».
6. Для Станции используйте предусмотренный Яндексом доступ к тестовому навыку
   для аккаунта владельца. Если консоль требует публикацию для выбранной
   поверхности, завершите её настройку и модерацию по инструкции Яндекса.
   Сам по себе работающий webhook не делает навык доступным на колонке.
7. Колонка должна использовать аккаунт с доступом к навыку. Произнесите
   «Алиса, запусти навык [активационное имя]».

## Ограничения и доступ

Сервер рассчитан на личный MVP: один процесс, один экземпляр, максимум 100
активных сессий. История и ожидающие ответы находятся в памяти и теряются при
перезапуске. Не включайте несколько workers или экземпляров: следующий запрос
может попасть в процесс без ожидающего ответа. Не используйте засыпающий хостинг.
Сессии очищаются после 10 минут при следующем обращении.

`ALICE_SKILL_ID` сверяет входящие данные, но не доказывает, что запрос пришёл
от Яндекса: JSON можно подделать. Публичный `/alice` может использовать посторонний.
Для личного теста ограничьте доступ к навыку в Яндексе; дополнительно можно задать
`ALLOWED_APPLICATION_IDS` через запятую, взяв `session.application.application_id`
из тестового запроса. Эти ID тоже не криптографическая аутентификация.
Перед широким запуском нужны ограничения запросов на хостинге, контроль затрат
и более надёжная проверка доступа. Не вводите конфиденциальные данные: вопросы
передаются Яндексу и OpenAI. Код не записывает тексты и ключи в логи.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты подменяют OpenAI: не требуют ключа и не тратят деньги. Проверяются формат
ответа, отсутствие ключа, выход, ошибки API, история, изоляция сессий, повторы,
обрезка длины и получение фонового ответа после лимита webhook.
Реальную связку проверяйте в тестовой консоли Яндекса после размещения.

## Если что-то не работает

- **Навык не отвечает:** проверьте URL `/alice`, HTTPS, состояние сервиса,
  один worker и постоянно работающий тариф. Яндекс ждёт всего 4,5 секунды
  включая доставку запроса и ответа.
- **Не удалось связаться с OpenAI:** проверьте ключ, баланс, имя модели
  и доступность API из выбранного региона размещения.
- **403:** `ALICE_SKILL_ID` не совпадает с ID навыка.
- **Колонка не находит навык:** проверьте активационное имя, доступ к навыку
  и аккаунт на колонке.
- **Ответ ещё готовится:** скажите «готово» чуть позже. Генерация ограничена
  тайм-аутом API 30 секунд; автоматических повторов платных запросов нет.
